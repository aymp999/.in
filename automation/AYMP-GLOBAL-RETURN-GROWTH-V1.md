# AYMP Global Return Growth v1

## Goal
Increase the probability of useful repeat visits from global audiences without promising permanent traffic.

## Return loop
Discover -> Receive value -> Save/share -> Choose follow-up -> Return.

## Homepage priorities
1. One clear global value proposition.
2. "Today's AYMP Insight" or latest useful insight.
3. Clear paths to Daily Zodiac, Formula Insights, Ask AYMP, Wellness and Global topics.
4. A visible reason to return tomorrow/week.
5. One primary CTA per section.

## Content cadence
- Daily: one short insight where practical.
- Weekly: one deeper feature.
- Monthly: one roundup or archive page.

## Measurement
Track returning users, engagement, top entry pages, CTA clicks and enquiries. Review trends rather than single-day changes.

## Global audience
Use concise English alongside Tamil where appropriate, avoid culturally opaque wording, and organize content around universal needs: decisions, wellbeing, timing, learning, food and curiosity.

## No guarantees
This system improves structure and measurement; it cannot guarantee permanent viewers or a fixed income.
