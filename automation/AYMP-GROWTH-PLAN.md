# AYMP AI Growth Engine v1

Mode: draft-only.

The engine will use existing AYMP content as inputs and prepare a daily growth queue for Today’s Zodiac, Global Discovery, Wellness Tip, Food Discovery, Latest Video, and Cosmic Challenge.

Safety rules:
- Existing website pages remain read-only.
- Existing zodiac databases remain read-only.
- No wallet private keys, seed phrases, passwords, or API keys are stored in the repository.
- Generated content is a draft until human approval.
- Future LLM access must use GitHub Secrets only.
- Emergency stop must fail closed.
