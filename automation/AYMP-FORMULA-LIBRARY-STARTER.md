# AYMP Formula Library Starter

## Methodology foundation
AYMP Jyotish Analysis considers:
- Birth foundation: rasi, nakshatra, lagna, tithi, karana, yoga, place and time.
- Lagna and lagna lord analysis.
- Nine-planet status, placement, dignity and relationships.
- Dasha, bhukti, anthara and current transit.
- Time-cycle considerations.
- Life-area mapping and remedial insight.

## Conceptual framework
AYMP Jyotish Guidance = Birth Foundation + Lagna Analysis + Nine-Planet Analysis + Planetary Strength/Relationship + Time Factors + Life-Area Mapping + Remedial Insight.

This is a conceptual representation of the AYMP analysis method, not a scientific mathematical law or a guarantee of outcomes.

## Content rule
Every public formula should contain:
1. Short insight.
2. Conceptual formula.
3. Brief explanation.
4. Clear context where needed.

Personalized guidance requires the relevant user-provided details and human review where the service is presented as expert analysis.
